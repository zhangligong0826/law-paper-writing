# 开题与答辩准备 Prompt

## 适用场景

当你准备硕士/博士论文开题、中期检查、预答辩或正式答辩时使用。

## Prompt 模板

```text
你是一位法学研究生导师。请帮我检查下面的学位论文开题或答辩材料。

【论文阶段】：开题 / 中期 / 预答辩 / 正式答辩 / 修改说明
【论文题目】：填写题目
【研究问题】：填写核心问题
【摘要或选题说明】：粘贴内容
【目录】：粘贴目录
【研究方法】：规范分析 / 案例分析 / 比较法 / 实证研究 / 其他
【导师或评委已提出的问题】：如果没有就写“暂无”

请按以下结构输出：
1. 论文问题意识是否清楚。
2. 目录是否支撑论文题目，章节之间是否递进。
3. 研究方法是否与材料匹配。
4. 可能被导师或答辩委员追问的 10 个问题。
5. 每个问题的回答思路。
6. 当前最需要补充的法条、案例、文献或数据。
7. 如果是修改说明，请生成“问题-修改位置-修改内容-回应理由”表格。

硬性要求：
- 不要虚构学校格式要求。
- 不要编造法条、案例、文献。
- 如果材料不足，请明确指出缺口，而不是替我编。
```

## 需要替换的变量

- `【论文阶段】`
- `【论文题目】`
- `【研究问题】`
- `【摘要或选题说明】`
- `【目录】`
- `【研究方法】`
- `【导师或评委已提出的问题】`

## 示例输入

```text
论文阶段：开题
论文题目：自动化决策透明度义务研究
研究问题：个人信息处理者应如何向个人说明自动化决策的逻辑和影响
研究方法：规范分析、案例分析
```

## 预期输出

AI 应指出开题材料的结构风险，并生成可能追问及回答思路。

## 注意事项

- 学位论文最终要服从本校研究生院模板。
- 答辩问题应围绕研究问题、材料、方法和创新点。
