# 去 AI 味与润色 Prompt

## 适用场景

当一段文字看起来像 AI 写的，存在空泛、过度平衡、模糊归因、政策意义虚高等问题时使用。

## Prompt 模板

```text
你是一位法学论文语言润色助手。请在不改变法律含义和引用信息的前提下，帮我去除下面文字的 AI 写作痕迹。

【目标类型】：CSSCI 投稿 / SSCI 投稿 / 学位论文 / 课程论文
【研究领域】：填写法学分支
【需要修改的文字】：粘贴原文
【必须保留的术语、法条、案例或文献】：逐条列出；如果没有就写“无”
【希望风格】：严谨克制 / 更像中文法学论文 / 更适合英文期刊 / 更适合学位论文

请按以下结构输出：
1. 先指出原文中明显的 AI 痕迹，例如空泛形容、机械过渡、模糊归因、模板化平衡、结论重复。
2. 给出修改原则。
3. 输出改写后的版本，段落数量尽量与原文一致。
4. 列出保留不改的法律术语、法条和案例。
5. 标出仍需人工补证或核查的位置。

硬性要求：
- 不要改变法条、案号、作者名、文献题名。
- 不要把正式法学论文改成口语表达。
- 不要新增未经提供的事实、案例、法条或文献。
- 不要过度使用“综上所述”“具有重要意义”“应当指出”等套话。
```

## 需要替换的变量

- `【目标类型】`
- `【研究领域】`
- `【需要修改的文字】`
- `【必须保留的术语、法条、案例或文献】`
- `【希望风格】`

## 示例输入

```text
目标类型：CSSCI 投稿
研究领域：个人信息保护法
需要修改的文字：随着数字经济的蓬勃发展，自动化决策问题日益凸显，具有重要研究意义。
必须保留：自动化决策、个人信息保护法第24条
希望风格：严谨克制
```

## 预期输出

AI 应把空泛表达改成具体问题表达，并标注需要补充材料的位置。

## 注意事项

- 去 AI 味不是降格为口语。
- 好的法学表达通常更具体、更有边界、更少夸张。
