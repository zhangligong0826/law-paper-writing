# 引用与脚注整理 Prompt

## 适用场景

当你的脚注、参考文献、法条引用格式混乱，需要统一为目标期刊或学校要求时使用。

## Prompt 模板

```text
你是一位法学论文引注格式助手。请帮我整理下面的引用，但必须把无法确认的信息标注为“需人工核对”。

【目标格式】：脚注式 / GB/T 7714 / Bluebook / 学校模板 / 目标期刊格式
【目标期刊或学校】：填写名称；如果没有就写“暂无”
【引用列表或脚注】：粘贴需要整理的内容
【使用语言】：中文 / 英文 / 中英混合

请按以下结构输出：
1. 先列出每条引用的问题：缺作者、缺题名、缺年份、缺页码、格式不统一、法条版本不明等。
2. 给出整理后的参考格式草案。
3. 对每条引用标注“可直接使用 / 需核查 / 信息不足不能整理”。
4. 对法条引用，说明需要核查法律名称、条号、版本和原文。
5. 对案例引用，说明需要核查案名、案号、法院、裁判日期和文书来源。
6. 对英文引用，说明是否需要按 Bluebook 或目标期刊体例进一步核对。

硬性要求：
- 不要凭空补作者、页码、案号、卷期。
- 不要声称完全符合某期刊格式，除非我提供了该期刊的最新投稿规范。
- 输出只能作为整理草案，正式投稿前必须人工核对。
```

## 需要替换的变量

- `【目标格式】`
- `【目标期刊或学校】`
- `【引用列表或脚注】`
- `【使用语言】`

## 示例输入

```text
目标格式：脚注式
目标期刊或学校：法学研究
引用列表或脚注：
王利明，民法典人格权编研究，中国法学，2020。
个人信息保护法第24条。
使用语言：中文
```

## 预期输出

AI 应指出缺页码、期刊卷期和法条版本，并给出整理草案。

## 注意事项

- 引用转换脚本只能辅助初稿整理，不能替代人工核对。
- 期刊格式要求变化快，应以投稿须知为准。
