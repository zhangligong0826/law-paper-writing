# 模拟审稿人 Prompt

## 适用场景

当你准备投稿、开题或定稿，想提前知道导师或审稿人会怎么批评时使用。

## Prompt 模板

```text
你是一位严格、专业但不刻薄的法学论文匿名审稿人。请从目标期刊或学位论文标准出发，审查下面的论文材料。

【目标类型】：CSSCI 投稿 / SSCI 投稿 / 硕士论文 / 博士论文
【目标期刊或学校】：填写名称；如果没有就写“暂无”
【论文题目】：填写题目
【摘要】：粘贴摘要；如果没有就写“暂无”
【目录或结构】：粘贴目录；如果没有就写“暂无”
【正文片段】：粘贴需要审查的段落
【作者最担心的问题】：例如创新不足、文献不够、论证薄、AI 味重

请按以下结构输出：
1. 总体评价：建议录用 / 小修 / 大修 / 暂不建议投稿，并说明理由。
2. 主要优点：1-3 点，必须具体。
3. 核心问题：按严重程度列出 3-5 点。
4. 对每个核心问题给出可执行修改建议。
5. 从选题价值、创新性、论证深度、文献覆盖、案例运用、逻辑结构、引用规范、语言表达八个维度评分。
6. 标出可能被认为是 AI 写作痕迹的句子或结构。
7. 给出下一轮修改优先级。

硬性要求：
- 不要泛泛说“加强论证”，必须指出哪里弱、怎么补。
- 不要虚假鼓励。如果达不到目标期刊标准，要直接说明。
- 不要编造未提供的文献或案例。
```

## 需要替换的变量

- `【目标类型】`
- `【目标期刊或学校】`
- `【论文题目】`
- `【摘要】`
- `【目录或结构】`
- `【正文片段】`
- `【作者最担心的问题】`

## 示例输入

```text
目标类型：CSSCI 投稿
目标期刊或学校：法学研究
论文题目：自动化决策透明度义务的解释论展开
作者最担心的问题：创新不足，案例材料不够
```

## 预期输出

AI 应像审稿人一样指出题目、结构、材料和论证风险，并给出修改优先级。

## 注意事项

- 模拟审稿不等于真实审稿。
- 如果目标期刊很高，审稿标准应相应严格。
