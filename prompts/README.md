# Prompt 模板库

这里的 Prompt 可以直接复制到 ChatGPT、Cursor、WorkBuddy 或其他 AI 助手中使用。你不需要懂编程，只要把模板里的 `【】` 替换成自己的论文信息。

## 选择指南

| 任务 | 文件 | 适合阶段 |
|:---|:---|:---|
| 判断题目是否值得写 | [topic-selection.md](topic-selection.md) | 选题、开题前 |
| 写文献综述 | [literature-review.md](literature-review.md) | 开题、引言、综述章节 |
| 核查法条、案例、文献 | [legal-verification.md](legal-verification.md) | 写作中、定稿前 |

| 模拟审稿人 | [reviewer-mode.md](reviewer-mode.md) | 投稿前、修改前 |
| 去 AI 味和润色 | [de-ai-polishing.md](de-ai-polishing.md) | 初稿后、投稿前 |
| 开题和答辩准备 | [thesis-defense.md](thesis-defense.md) | 学位论文阶段 |

## 使用方法

1. 打开对应文件。
2. 复制「Prompt 模板」中的完整内容。
3. 替换 `【论文题目】`、`【目标期刊】`、`【草稿内容】` 等占位符。
4. 如果 AI 要引用法条、案例、文献，要求它标出“需要人工核查”的位置。
5. 不要把 AI 生成的法条、案号、页码直接当作最终结果。

## 输出原则

所有 Prompt 都默认遵守三条规则：

- 不编造法条、案例、文献。
- 对不确定信息明确标注“需核查”。
- 输出要能直接服务论文修改，而不是泛泛建议。
