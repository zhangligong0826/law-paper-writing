# 文献综述 Prompt

## 适用场景

当你已经收集了一批论文，但综述写成了“张三认为、李四认为、王五认为”的罗列时使用。

## Prompt 模板

```text
你是一位法学论文写作导师。请帮我把下面的文献材料整理成有问题意识的文献综述框架。

【论文题目】：填写题目
【研究问题】：填写本文要回答的问题
【目标类型】：CSSCI 投稿 / SSCI 投稿 / 学位论文
【文献材料】：逐条列出作者、题名、年份、核心观点；如果信息不完整，请保留原样并标注需核查
【我的初步立场】：填写你的观点；如果没有就写“尚未形成”

请按以下结构输出：
1. 现有研究可以分成哪几类观点。
2. 每类观点的核心主张、代表作者和可能不足。
3. 哪些文献是基础文献，哪些是近 5 年需要重点关注的文献。
4. 现有研究的真实缺口是什么，不要虚构缺口。
5. 本文可以如何回应这个缺口。
6. 给出一版文献综述段落提纲。
7. 给出 1-2 段示范文字，但必须只使用我提供的文献信息。
8. 列出仍需补充检索的关键词和数据库。

硬性要求：
- 不要编造我没有提供的作者、论文、年份、页码。
- 不要使用“学界普遍认为”这种无归因表达。
- 不要把文献综述写成流水账，要体现比较和评价。
```

## 需要替换的变量

- `【论文题目】`
- `【研究问题】`
- `【目标类型】`
- `【文献材料】`
- `【我的初步立场】`

## 示例输入

```text
论文题目：自动化决策透明度义务的解释论展开
研究问题：《个人信息保护法》第24条中的透明度义务应如何具体化
文献材料：
1. 作者A，2021，认为算法透明应强调告知义务。
2. 作者B，2022，认为算法解释权应区分一般解释和个案解释。
3. 作者C，2023，关注平台算法治理和行政监管。
```

## 预期输出

AI 应把文献分组，指出分歧和缺口，并给出综述提纲。

## 注意事项

- 文献综述的核心不是“列全”，而是“服务你的研究问题”。
- 没有读过原文的文献不要让 AI 强行总结。
