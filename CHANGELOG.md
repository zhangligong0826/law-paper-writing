# Changelog

## v1.2.0

- Repositioned the project as a beginner-friendly legal academic writing toolkit.
- Rewrote `README.md` around copyable prompts, Skill installation, examples, and legal verification boundaries.
- Added the `prompts/` library for topic selection, literature review, legal verification, citation cleanup, reviewer mode, de-AI polishing, and thesis defense.
- Added the `examples/` directory with complete non-code workflows.
- Added `LICENSE`, `CONTRIBUTING.md`, and `ROADMAP.md`.
- Improved `citation-converter.py` handling for common GB/T 7714 journal formats.
- Added unit tests for citation conversion behavior.

## v1.1.0

- Expanded the original Skill into a full law-paper-writing reference set.
- Added guides for citation workflow, Word document workflow, journal selection, legal verification, English writing, and de-AI patterns.
- Added an initial citation conversion helper script.
