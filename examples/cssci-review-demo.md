# 示例：CSSCI 模拟审稿意见

以下示例展示 AI 应如何以审稿人视角提出具体、可执行的修改意见。实际使用时，请把你的摘要、目录和正文片段粘贴到 [prompts/reviewer-mode.md](../prompts/reviewer-mode.md)。

## 输入摘要

```text
本文以自动化决策透明度义务为研究对象，分析个人信息保护法第24条在平台算法治理中的适用问题。文章认为，应当通过完善算法透明机制保障个人权益。
```

## 模拟审稿输出示例

### 总体评价

建议大修后再考虑投稿。选题具有现实意义，但摘要中的核心问题仍偏宽，论证对象没有从“算法治理”收束到“第24条透明度义务的解释问题”。

### 主要优点

1. 选题回应了个人信息保护法实施后的真实争议。
2. 文章尝试将平台算法实践与法律义务解释连接起来。
3. 题目适合展开规范分析和案例分析。

### 核心问题

| 问题 | 说明 | 修改建议 |
|:---|:---|:---|
| 问题意识不够尖锐 | “完善算法透明机制”仍是政策口号 | 改为“透明度义务具体要求说明哪些信息” |
| 规范对象不清 | 第24条包含透明、公平合理、拒绝权等多个层面 | 明确本文只讨论透明度义务，或说明各义务关系 |
| 案例材料不足 | 摘要没有说明实践困境来自哪里 | 增加典型争议、监管案例或裁判材料，并标注需核查 |
| 创新表达偏弱 | “保障个人权益”过于常见 | 强调解释框架或分层披露标准的推进 |

### 修改优先级

1. 重写摘要第一句，明确法律适用困境。
2. 收窄题目，避免覆盖整个算法治理。
3. 补充案例或执法材料，证明问题不是纯理论想象。
4. 把结论从“完善机制”改成可操作规则。

### AI 痕迹提示

以下表达容易显得空泛：

- “具有重要现实意义”
- “完善算法透明机制”
- “保障个人权益”

建议改成具体问题表达，例如：

```text
现行规范并未明确个人信息处理者在自动化决策场景中应说明算法逻辑、影响因素还是个案结果理由。
```

## 使用提醒

模拟审稿应尽量具体到论文结构和段落，不应只输出“加强论证”“补充文献”。
