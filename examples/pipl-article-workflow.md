# 示例：从个人信息保护法自动化决策到 CSSCI 论文框架

这个示例演示如何把一个模糊想法推进成可写的法学论文方案。示例中的法条、案例和文献均应在正式写作前重新核查。

## 1. 初始想法

```text
我想写一篇关于个人信息保护法中自动化决策的论文，关注平台算法推荐、大数据杀熟和算法透明。
```

## 2. 先用选题 Prompt

使用 [prompts/topic-selection.md](../prompts/topic-selection.md)，填写：

```text
研究方向：个人信息保护法
初步题目：自动化决策的法律规制
目标类型：CSSCI 投稿
我目前的想法：平台算法推荐和差别定价可能损害个人权益，但现有规则比较原则化。
已有材料：《个人信息保护法》第24条，平台治理相关政策，案例尚未系统检索。
```

## 3. AI 应该给出的改题方向

较好的题目不应停留在“法律规制”这种大词上，可以改成：

```text
自动化决策透明度义务的解释论展开
```

或：

```text
个人信息保护法中自动化决策拒绝权的适用边界
```

## 4. 研究问题

可聚焦为：

```text
《个人信息保护法》第24条要求个人信息处理者保证自动化决策的透明度，但“透明”到底要求说明什么、向谁说明、说明到什么程度，仍需要解释论展开。
```

## 5. 材料清单

正式写作前至少需要核查：

| 类型 | 待核查材料 | 核查来源 |
|:---|:---|:---|
| 法条 | 《个人信息保护法》第24条原文与现行有效状态 | 国家法律法规数据库 |
| 规范文件 | 算法推荐、平台治理、个人信息保护相关规定 | 国家网信办、国务院部门官网 |
| 案例 | 涉自动化决策、算法推荐、差别定价的裁判文书 | 裁判文书网、北大法宝 |
| 文献 | 自动化决策、算法透明、个人信息权益保护论文 | CNKI、万方、Google Scholar |

## 6. 可能的论文结构

```text
一、问题的提出：自动化决策透明度义务为何需要解释
二、规范基础：《个人信息保护法》第24条的义务结构
三、适用难点：透明度、商业秘密与算法可解释性的冲突
四、解释路径：分层说明义务与场景化披露标准
五、制度衔接：监管执法、个人权利救济与平台合规
结论
```

## 7. 审稿人可能质疑

- 题目是否只是重复已有算法治理研究。
- 是否有足够案例材料支撑“实践困境”。
- 是否区分了算法透明、算法解释和个人信息告知义务。
- 是否把政策倡导写成了教义学论证。
- 是否能给出可操作的解释标准。
