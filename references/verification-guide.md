# 法律核查工具集成指引

> 法学论文的引用准确性和反幻觉机制是学术诚信的基石。本文档提供可执行的核查流程，帮助你在写作过程中核实法条、案例和学术文献。

---

## 一、法条核实流程

### 1.1 核实步骤

```
Step 1: 确认法律名称 → 全称是否正确？
Step 2: 确认条文编号 → 条、款、项是否准确？
Step 3: 确认条文内容 → 文字表述是否与官方一致？
Step 4: 确认生效状态 → 是否为现行有效版本？
Step 5: 确认修正/修订 → 是否有最新修正？
```

### 1.2 核实优先级

| 来源 | 可信度 | 核实方式 |
|------|--------|---------|
| 国家法律法规数据库 (flk.npc.gov.cn) | 最高 | 官方来源，最终依据 |
| 北大法宝 (www.pkulaw.com) | 高 | 学术版含释义和案例关联 |
| 法律出版社法规汇编 | 高 | 权威出版物 |
| 其他法律数据库 | 中 | 需与官方来源交叉验证 |
| AI 生成的内容 | 零 | 必须逐条核实，不可直接引用 |

### 1.3 WebFetch 核实模板

核实法条时，使用 WebFetch 访问国家法律法规数据库：

**核实法律条文：**
- URL: `https://flk.npc.gov.cn/` → 搜索法律名称
- prompt 示例：`查找《中华人民共和国民法典》第577条的原文内容，确认是否包含"当事人一方不履行合同义务或者履行合同义务不符合约定的"这段文字`

**核实法律修正状态：**
- prompt 示例：`查找《中华人民共和国公司法》的最新修正版本，确认最新修正年份和主要修改内容`

### 1.4 常见法条核实陷阱

| 陷阱 | 说明 | 防范方法 |
|------|------|---------|
| 引用已废止条文 | 旧法废止后引用旧条文 | 标注"（20XX年修正前）"或使用最新版 |
| 条款编号错误 | 条、款、项混用 | 仔细核对原文编号 |
| 漏引修正内容 | 引用修正前的内容 | 查找最新修正决定 |
| 法名简称错误 | 简称不统一 | 首次出现用全称，注明简称 |

## 二、案例核实流程

### 2.1 核实步骤

```
Step 1: 确认案例名称 → 当事人名称是否正确？
Step 2: 确认案号 → 法院简称+年份+案件类型+编号
Step 3: 确认审理法院 → 一审/二审/再审法院名称
Step 4: 确认裁判要旨 → 引用的裁判理由是否准确？
Step 5: 确认裁判日期 → 裁判文书作出日期
```

### 2.2 案号格式规范

| 法院层级 | 案号格式 | 示例 |
|---------|---------|------|
| 最高人民法院 | (年份)最高法(民/刑/行)终/申/抗XX号 | (2023)最高法民申1234号 |
| 高级人民法院 | (年份)省简称(民/刑/行)终/申XX号 | (2023)京民终567号 |
| 中级人民法院 | (年份)市简称(民/刑/行)终/初XX号 | (2023)京01民初890号 |
| 基层人民法院 | (年份)市简称区简称(民/刑/行)初XX号 | (2023)京0105民初1234号 |

### 2.3 WebFetch 核实模板

**核实最高法指导性案例：**
- URL: `https://www.court.gov.cn/shenpan-gengduo-xiangqing-XXXX.html`（指导性案例页面）
- prompt 示例：`查找最高人民法院第XX号指导性案例的基本信息和裁判要旨`

**核实一般案例：**
- URL: `https://wenshu.court.gov.cn/`（中国裁判文书网）
- prompt 示例：`查找案号为(2023)最高法民申XX号的裁判文书，确认裁判要旨是否包含XX内容`

### 2.4 案例核实检查清单

- [ ] 案例名称中的当事人名称是否准确
- [ ] 案号格式是否符合规范
- [ ] 审理法院层级是否标注正确
- [ ] 引用的裁判理由是否有引号标注（逐字引用时）
- [ ] 案例是否为已生效裁判（非上诉中）
- [ ] 指导性案例编号是否与最高法公布的编号一致

## 三、学术文献核实流程

### 3.1 核实步骤

```
Step 1: 确认作者姓名 → 是否真实存在该学者？
Step 2: 确认论文标题 → 标题是否与发表版本一致？
Step 3: 确认期刊名称 → 期刊是否真实存在？
Step 4: 确认年份/卷/期/页码 → 是否对应？
Step 5: 确认核心观点 → 引用的观点是否确实在该文中出现？
```

### 3.2 WebFetch 核实模板

**核实中文学术文献：**
- URL: `https://www.cnki.net/`（中国知网）
- prompt 示例：`查找学者XXX在《中国法学》XXXX年第X期发表的论文，确认标题和页码`

**核实英文学术文献：**
- URL: `https://scholar.google.com/`
- prompt 示例：`Search for the paper titled "XXX" by author XXX, published in journal XXX in year XXXX. Confirm the volume, issue, and page numbers.`

### 3.3 识别 AI 编造文献的特征

AI 生成文本中可能出现以下虚构文献特征：

| 特征 | 说明 | 核实方法 |
|------|------|---------|
| 学者姓名真实但论文不匹配 | 用真实学者的名字编造论文标题 | 在 CNKI 搜索该学者+标题 |
| 期刊名称真实但卷期不匹配 | 真实期刊但卷期号不存在 | 查看期刊官网的往期目录 |
| 页码超出合理范围 | 页码不符合期刊页数规模 | 检查该期期刊总页数 |
| 作者合作不存在 | 编造的多作者论文 | 搜索任一作者的其他论文 |
| 观点张冠李戴 | 真实论文但引用的观点不在其中 | 查看论文原文 |

## 四、系统化核实流程（推荐）

### 4.1 写作中实时核实

在写作过程中，每引用一条法条/案例/文献，立即执行以下快速核实：

```
法条引用 → flk.npc.gov.cn 搜索确认（30秒）
案例引用 → 北大法宝搜索案号确认（1分钟）
文献引用 → CNKI 搜索作者+标题确认（1分钟）
```

### 4.2 完稿后批量核实

论文完成后，按以下流程批量核实：

1. **提取所有法条引用** → 逐条在国家法律法规数据库核实
2. **提取所有案例引用** → 逐个在北大法宝或裁判文书网核实
3. **提取所有学术文献引用** → 逐条在 CNKI/Google Scholar 核实
4. **交叉验证** → 抽查 20% 的引用，用第二种来源再次确认

### 4.3 核实时间估算

| 论文规模 | 法条 | 案例 | 文献 | 总估时 |
|---------|------|------|------|--------|
| 期刊论文（1.5万字） | 10-20 条 | 5-10 个 | 30-50 条 | 2-3 小时 |
| 硕士学位论文（3万字） | 20-40 条 | 10-20 个 | 80-120 条 | 5-8 小时 |
| 博士学位论文（10万字） | 50-100 条 | 20-40 个 | 200-400 条 | 15-20 小时 |
