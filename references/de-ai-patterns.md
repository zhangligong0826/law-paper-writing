# 法学领域 AI 写作痕迹完整清单

> 本文档是法学论文去AI味的核心参考资料。基于 Wikipedia "Signs of AI writing" 指南的方法论，针对中文法学学术写作场景进行了系统性适配。

---

## 一、内容层面 AI 痕迹（5 种模式）

### 模式 1：案例重要性膨胀

**问题本质：** AI 倾向于将普通案例夸大为"里程碑式""标志性"判决，即使该案例在法律体系中并无特殊地位。

**典型表现：**
- 将一个基层法院或中级法院的普通判决形容为"具有里程碑意义"
- 用"开创性""标志性""重大突破"等词修饰例行裁判
- 将个案上升为"确立了XX原则"（实际只是对已有原则的常规适用）
- 过度渲染某一判决的"辐射效应""示范效应"

**识别标志词：** 里程碑式、标志性、开创性、重大突破、历史性、划时代、具有划时代意义

**改写原则：**
- 实事求是地评价案例地位：最高法指导性案例可以适当强调，但一般案例用"具有参考价值"即可
- 区分"首次"和"里程碑"：首次适用某条款≠里程碑判决
- 用具体影响替代虚高评价：不说"具有深远影响"，而说"已有N个下级法院在类似案件中参照该裁判思路"

**示例：**
- ❌ "该判决具有里程碑式的意义，标志着我国司法实践迈入新阶段"
- ✅ "该判决明确了XX条款在XX情形下的适用标准，此后已有多个下级法院参照适用"

### 模式 2：政策意义虚高

**问题本质：** AI 倾向于在论文结尾或引言中夸大研究的政策影响，使用空泛的宏大叙事。

**典型表现：**
- "具有深远的理论与实践意义"
- "为完善XX制度提供了重要参考"
- "对推动法治建设具有积极意义"
- "为后续研究奠定了坚实基础"

**识别标志词：** 深远意义、理论与实践、重要参考、积极意义、坚实基础、重要价值、重大贡献

**改写原则：**
- 用具体贡献替代空泛意义：不说"具有深远意义"，而说"提出了XX标准的三个构成要件"
- 政策建议具体化：不说"对完善立法有重要参考"，而说"建议在XX法修订中增设XX条款"

**示例：**
- ❌ "本文的研究对推动我国XX制度的完善具有深远的理论与实践意义"
- ✅ "本文提出的XX认定标准，可为《XX法》第X条的修订提供具体参考"

### 模式 3：学术贡献夸大

**问题本质：** AI 倾向于用"填补空白""首次""独创"等词形容论文贡献，即使该研究只是增量改进。

**典型表现：**
- "填补了XX领域的研究空白"
- "学界尚无对此问题的系统研究"
- "本文首次从XX视角出发"
- "开辟了XX研究的新路径"

**识别标志词：** 填补空白、尚无研究、首次从、独创、开辟新路径、率先提出、前所未有

**改写原则：**
- 谨慎使用"填补空白"：除非确实经过全面文献检索确认无人涉及
- 用"补充"替代"空白"：说"在既有研究基础上进一步探讨了..."更稳妥
- "首次"需有依据：确实要声称首次，须附文献检索说明

**示例：**
- ❌ "学界尚无人从XX视角对该问题进行系统研究"
- ✅ "目前从XX视角进行专门研究的文献较少，主要集中在A、B两方面，对C方面的探讨尚不充分"

### 模式 4：模糊归因

**问题本质：** AI 倾向于将观点归因于"学界""通说""一般认为"等模糊主体，而非具体文献。

**典型表现：**
- "学界普遍认为"
- "通说认为"
- "一般认为"
- "学界对此已达成共识"
- "多数学者认为"
- "有学者指出"

**识别标志词：** 学界普遍、通说、一般认、达成共识、多数学者、有学者、主流观点

**改写原则：**
- 归因到具体学者或文献："张三（2020）认为..."而非"学界认为..."
- 对真正的通说可以标注"通说"，但需注明经典文献出处
- 存在争议时明确列举对立观点及各自代表学者

**示例：**
- ❌ "学界普遍认为，该条款的适用应当严格限定"
- ✅ "对该条款适用范围的限定，主流观点采严格解释立场（参见王利明《XX》第X页），但也有学者主张相对宽松的解释方案（参见崔建远《XX》第X页）"

### 模式 5：公式化结论

**问题本质：** AI 生成的论文结论高度模板化，缺乏针对具体论题的个性化总结。

**典型表现：**
- "综上所述，本文认为..."
- "通过上述分析可以得出..."
- "基于以上讨论，本文提出以下建议..."
- 几乎每段都以"综上所述""因此"开头

**识别标志词：** 综上所述、通过上述分析、基于以上讨论、由此可知、总之

**改写原则：**
- 结论应回扣具体论点，而非空泛总结全文
- 避免每段都用"综上所述"，可以变化为"从上述XX可以看出""本案表明""由此可见"
- 提出具体、可操作的建议或判断，而非笼统表态

## 二、语言与语法层面 AI 痕迹（6 种模式）

### 模式 6：法学 AI 词汇清单

以下是 AI 生成中文学术论文时高频出现的词汇。单独出现一个词不一定有问题，但当一段话中密集出现 3 个以上时，高度可疑：

**高频 AI 词汇（25 个）：**

| 词汇 | 出现频率 | 替代方案 |
|------|---------|---------|
| 值得注意的是 | 极高 | 删去，直接陈述内容 |
| 综上所述 | 极高 | 根据前文分析 / 从以上讨论可见 |
| 毋庸置疑 | 高 | 删去，直接陈述事实 |
| 应当指出 | 高 | 删去，直接写要指出的内容 |
| 不仅如此 | 高 | 此外 / 同时 / 另一方面 |
| 具有重要意义 | 高 | 具体说明什么意义 |
| 发挥着重要作用 | 高 | 用具体效果替代 |
| 提供了重要参考 | 高 | 具体说明参考了什么 |
| 具有里程碑意义 | 高 | 根据案例实际影响评价 |
| 深入研究 | 中 | 具体说明研究了什么 |
| 系统梳理 | 中 | 具体说明梳理了哪些内容 |
| 全面分析 | 中 | 具体说明分析了哪些方面 |
| 积极意义 | 中 | 具体说明积极在哪里 |
| 不断完善 | 中 | 说明完善了什么 |
| 日益凸显 | 中 | 说明什么问题在什么条件下凸显 |
| 亟待解决 | 中 | 说明为什么急迫、解决什么 |
| 蓬勃发展 | 中 | 具体描述发展状况 |
| 从根本上说 | 中 | 删去或替换为"本质上" |
| 不可忽视 | 中 | 具体说明不能忽视什么 |
| 在此基础上 | 中 | 直接进入新内容，省略过渡 |
| 与此同时 | 中 | 同时 / 另一方面 |
| 进一步 | 中 | 直接写后续内容，省略"进一步" |
| 极其 | 中 | 删去或用更精确的修饰 |
| 至关重要 | 中 | 具体说明为什么重要 |

**改写原则：**
- **不等于全删**：其中某些词在法学论文中是合理的（如"综上所述"在全文结论段使用一次），关键是**使用频率和密度**
- **用具体替代抽象**："具有重要意义"→"为XX条款的解释提供了三个层次的裁判标准"
- **删减冗余修饰**："进行深入的系统梳理"→"梳理"即可

### 模式 7：机械过渡词链

**问题表现：** "首先...其次...再次...最后..." 这种四段式机械排列，每段开头完全对称。

**改写原则：**
- 不需要每个论点都用序数词开头
- 可以用内容本身作为过渡："在实体法层面...""在程序法层面..."
- 论点之间用逻辑连接而非序数连接："与XX相对应的是...""除了XX之外，还应考虑..."

### 模式 8：过度使用特定过渡短语

**问题表现：**
- "进一步""值得注意的是""在此基础之上"高频出现
- 每段都以"此外""同时"开头
- 过度使用"换言之""具体而言"

**改写原则：**
- 段落之间不一定每段都需要过渡词，可以自然衔接
- "值得注意的是"几乎总是可以删去，直接写值得注意的内容
- "进一步"在连续出现 2 次以上时应当删减

### 模式 9：公式化"一方面...另一方面..."平衡

**问题表现：** AI 倾向于对所有有争议的问题采用"一方面肯定、另一方面否定"的平衡结构，即使作者实际有明确立场。

**改写原则：**
- 如果作者有明确立场，不要强行平衡。可以直接表达倾向性观点，同时回应反对意见
- 即使需要平衡，也要明确表明作者最终倾向哪一方
- "一方面...另一方面..."在同一篇文章中最多出现 2-3 次

### 模式 10：被动/无主句泛滥

**问题表现：**
- "该问题被广泛讨论"
- "XX制度被认为具有"
- "XX条款的适用应当被严格限定"
- 大量句子缺少明确主语

**改写原则：**
- 中文学术写作中，主动句更自然
- 但注意：法律条文的引用和裁判要旨的复述中，被动句是正常的
- 判断标准：如果被动句不是引述法律原文，考虑改为主动句

### 模式 11：同义词循环

**问题表现：** 同一法律概念在文中用 3-4 个不同表述交替出现。例如"合同解除权"→"解除合同的权利"→"合同的解除权利"→"解除权"。

**改写原则：**
- 法学写作中术语一致性比词汇多样性更重要
- 一个法律概念确定一个表述，全文统一使用
- 如果需要变化，在首次出现时用"（以下简称XX）"确立简称

## 三、论证结构层面 AI 痕迹（5 种模式）

### 模式 12：IRAC 结构机械套用

**问题表现：** 每个案例都机械地按照"Issue→Rule→Application→Conclusion"四步展开，即使某类分析不需要这种结构。

**改写原则：**
- IRAC 是有用的分析工具，但不应对所有段落强行套用
- 有些论证更适合"先列法条依据，再分析案例，最后得出结论"的三步结构
- 有些论证适合直接切入分析，不需要先单独列"法律依据"

### 模式 13：过度平衡论证

**问题表现：** 对每个争议问题都给出等量的正反两方面论述，不做判断、不表态。读完后不知道作者的观点是什么。

**改写原则：**
- 法学论文要有立场。你可以承认对立观点的合理性，但最终必须做出判断
- 结构建议：先承认对立观点（1-2句）→说明为什么你的观点更合理（重点展开）→回应反对意见可能提出的质疑
- "学术中立"≠"和稀泥"

### 模式 14：论据堆砌无逻辑递进

**问题表现：** 列举多个案例或多个学者的观点，但只是平行排列，没有从弱到强或从一般到特殊的逻辑递进。

**改写原则：**
- 论据排列应有逻辑层次：
  - 从上位法到下位法
  - 从原则到规则
  - 从一般案例到典型案例
  - 从国内法到比较法
- 使用明确的逻辑连接词，体现递进关系

### 模式 15：结论与论点简单重复

**问题表现：** 结论段只是把引言和正文中的观点原封不动复述一遍，缺乏升华、延伸或具体建议。

**改写原则：**
- 结论应当：回扣论点（但不是重复）→ 总结论证路径 → 指出研究局限 → 提出具体后续方向
- 避免"本文通过以上分析得出如下结论"后简单罗列要点

### 模式 16：三段论机械应用

**问题表现：** "问题的提出→问题的分析→问题的解决"这种三段式结构应用于所有论文，即使论题不适合。

**改写原则：**
- 三段论是常见结构，但不是唯一结构
- 有些论文适合：先破后立（先批评现有观点，再提出新观点）
- 有些论文适合：总-分-总（先概括框架，再逐个展开）
- 根据论题选择最合适的结构

## 四、风格与格式层面 AI 痕迹（5 种模式）

### 模式 17：段落长度过于均匀

**问题表现：** 每段都是 200-300 字，段落长度几乎完全一致，缺乏长短变化。

**改写原则：**
- 法学论文不需要每段长度一致
- 核心论证段落可以长一些（400-500字）
- 过渡和说明段落可以短一些（100-150字）
- 一个关键判断可以独立成段（一句话段落）

### 模式 18：小标题格式机械化

**问题表现：** "一、问题的提出""二、XXX的分析""三、完善建议"——这种高度模板化的小标题在多篇论文中完全相同。

**改写原则：**
- 小标题应反映论文的具体论点，而非模板化表达
- 好的小标题示例：" XX 条文的解释路径争议""从 XX 案看 XX 条款的适用边界""比较法视野下的 XX 制度完善"
- 小标题之间应有逻辑递进关系，而非简单的并列

### 模式 19：过度使用粗体强调

**问题表现：** 在正文中频繁使用粗体标记关键词，影响学术文本的严肃性。

**改写原则：**
- 法学论文正文一般不用粗体强调（例外：法条名称、案例名称可加粗或用书名号）
- 如果需要强调，通过位置（句首）或措辞强调，而非格式强调

### 模式 20：破折号/省略号滥用

**问题表现：** 频繁使用破折号（——）做补充说明，或省略号（……）做结尾。

**改写原则：**
- 破折号在法学论文中使用频率应很低，每篇不超过 2-3 处
- 省略号在正文中一般不使用（引用原文截断除外）
- 补充说明改用括号或另起一句

### 模式 21：标题与正文重复

**问题表现：** 标题是"问题的提出"，正文第一句是"本文要探讨的问题是..."，标题是"完善建议"，正文第一句是"针对上述问题，本文提出以下建议..."

**改写原则：**
- 标题和正文第一句不应简单重复
- 正文第一句应直接切入实质内容，而非"报菜名式"复述标题

## 五、填充与套话层面 AI 痕迹（5 种模式）

### 模式 22：填充短语

**典型填充短语（按频率排序）：**

| 填充短语 | 替代方案 |
|---------|---------|
| 在当前的背景下 | 直接说明背景或删去 |
| 在此基础之上 | 直接进入新论点 |
| 不可忽视的是 | 直接说不可忽视的内容 |
| 从某种意义上说 | 删去或具体说明什么意义 |
| 事实上 | 删去（除非确实存在与此前表述不同的事实） |
| 毫无疑问 | 删去 |
| 不言而喻 | 删去 |
| 简而言之 | 删去，直接写简洁表述 |
| 具体来说 | 删去，直接写具体内容 |
| 总而言之 | 用具体总结替代 |

### 模式 23：虚假承诺式结论

**问题表现：** "期待学界能够给予更多关注""为后续研究奠定基础""本文的局限性将在未来的研究中进一步完善"。

**改写原则：**
- 如果确实有具体的研究展望，写清楚后续研究可能涉及的具体问题
- 不需要每个论文结尾都说"期待学界关注"
- 局限性部分应具体指出哪些问题没有解决，而非笼统说"研究不够深入"

### 模式 24：过度修饰

**问题表现：** "深刻的""全面的""系统的""详尽的"等修饰语高频出现，但实际内容并不支撑这些修饰。

**改写原则：**
- 让内容自己说话。如果分析真的深入，读者能感受到
- 一个段落中出现 2 个以上修饰性形容词时应当警惕
- "深刻的分析"→直接写出分析结论

### 模式 25：空泛展望

**问题表现：** "随着法治建设的不断推进""随着XX制度的日益完善""在全面依法治国的背景下"。

**改写原则：**
- 法学论文应当立足于具体法律问题，而非宏大的政治叙事
- 如果需要交代背景，用具体事件或法律变迁替代空泛表述
- "随着法治建设的不断推进"→"2023年《XX法》修订后，XX问题面临新的挑战"

### 模式 26：号召式结尾

**问题表现：** "应当引起学界的重视与关注""需要理论与实践的共同努力""立法机关应当及时予以回应"。

**改写原则：**
- 法学论文的核心是论证，不是号召
- 如果要提出立法建议，具体到条款层面
- 结尾应自然收束，不需要"呼吁""号召"

## 七、4 步改写流程

### 步骤 1：识别

通读全文，标记所有上述 26 种 AI 痕迹。重点关注：
- AI 词汇密度（一段话中 ≥3 个）
- 模糊归因（"学界""通说"无出处）
- 公式化结构（三段论、平衡论证、IRAC 套用）
- 空泛修饰（无实际内容的形容词）

### 步骤 2：草稿改写

按照改写技术速查表逐一修正。注意：
- 保持法学论文的正式语体，不要"口语化"
- 术语一致性比词汇多样性更重要
- 法律条文和案例引用保持原样，不"改写"

### 步骤 3：审计

自问："这段文字哪里暴露了 AI 写作痕迹？"逐段检查：
- 还有哪些 AI 词汇残留？
- 过渡是否自然（而非机械）？
- 论证是否有明确的逻辑递进？
- 结论是否回扣了具体论点（而非空泛总结）？

### 步骤 4：最终改写

根据审计结果进行最终修正，确认：
- AI 词汇密度 ≤ 每段 1 个
- 无模糊归因（所有"学界认为"都有出处）
- 段落长度有变化
- 小标题反映具体论点
