# 投稿与答辩检查清单

> 投稿前和答辩前逐项检查，避免低级错误。

---

## 一、CSSCI 核心期刊投稿清单

### 1.1 内容审查

- [ ] **论点明确性**：全文的核心论点是否在一句话内可以表述清楚？
- [ ] **论证充分性**：每个子论点是否有足够的论据支撑？
- [ ] **文献覆盖度**：是否检索并引用了近 5 年的核心文献？
- [ ] **案例支撑**：是否有具体的司法案例或法律条文支撑理论分析？
- [ ] **创新性**：与既有文献相比，本文的新贡献是什么？（能说出 1-2 点即可）
- [ ] **逻辑连贯**：各章节之间是否有清晰的逻辑递进关系？
- [ ] **语言质量**：是否通读全文修改了病句、错别字、标点错误？
- [ ] **去 AI 味**：是否使用 de-ai-patterns 清单逐段检查了 AI 写作痕迹？

### 1.2 格式审查

- [ ] **字数**：是否在目标期刊要求的字数范围内？
- [ ] **摘要**：是否有中英文摘要（部分期刊要求）？摘要是否包含研究目的、方法、结论？
- [ ] **关键词**：是否有 3-5 个关键词？是否准确反映论文主题？
- [ ] **注释体例**：是否按目标期刊要求的引注规范排版？（GB/T 7714 或脚注式）
- [ ] **参考文献**：参考文献列表是否完整？格式是否统一？
- [ ] **标题层次**：标题编号是否符合期刊要求？（一、（一）、1. 等）
- [ ] **页面设置**：字体、字号、行距、页边距是否符合要求？
- [ ] **作者信息**：是否按要求标注作者、单位、基金项目？

## 二、SSCI 期刊投稿清单

### 2.1 内容审查

- [ ] **研究问题清晰**：研究问题是否在引言中明确提出？
- [ ] **文献综述充分**：是否涵盖了该领域的主要英文文献？
- [ ] **方法论说明**：研究方法是否有清晰的说明和正当性论证？
- [ ] **论证逻辑**：论证是否遵循法律分析的逻辑规范？
- [ ] **贡献声明**：是否明确指出了本文的学术贡献（contribution statement）？
- [ ] **政策启示**：是否有 policy implications 部分（部分期刊要求）？

### 2.2 语言质量

- [ ] **英文表达**：是否经过英文母语者或专业润色服务检查？
- [ ] **法律术语**：英文法律术语使用是否准确？（注意中美法律术语差异）
- [ ] **语法正确**：是否有语法错误、拼写错误、标点错误？
- [ ] **行文流畅**：段落衔接是否自然？

### 2.3 引用格式

- [ ] **Bluebook 规范**：所有引用是否符合 Bluebook 21st Edition？
- [ ] **法条引用**：中国法条的英文引用是否有可靠译本？
- [ ] **案例引用**：案例引用格式是否正确？
- [ ] **参考文献列表**：是否有完整的参考文献列表（部分期刊要求）？

### 2.4 匿名审稿注意

- [ ] **匿名化**：是否删除了所有可能暴露作者身份的信息？（致谢、基金项目编号、个人声明等）
- [ ] **自我引用处理**：引用自己以往论文时，用"作者(年份)"替代真实姓名
- [ ] **文档属性**：Word 文件的 Properties/作者信息是否已匿名化？

### 2.5 Cover Letter 要点

- [ ] 说明论文题目和核心贡献
- [ ] 说明为何适合该期刊
- [ ] 说明与既有文献的差异
- [ ] 声明未同时投他刊、无利益冲突
- [ ] 控制在 1 页以内

## 三、学位论文答辩前检查清单

### 3.1 论文结构完整性

- [ ] **封面**：论文题目、作者、导师、学校、专业、日期
- [ ] **中文摘要**（500-1000字）：研究目的、方法、主要结论、创新点
- [ ] **英文摘要**：与中文摘要对应，英文表达准确
- [ ] **目录**：自动生成，页码准确
- [ ] **引言/绪论**：研究背景、问题提出、研究方法、结构安排
- [ ] **正文各章**：每章有独立的引言和本章小结
- [ ] **结论**：总结全文论证，指出研究局限，展望后续方向
- [ ] **参考文献**：格式统一，数量充足（博士学位论文一般 100-200 篇）
- [ ] **致谢**：简洁得体
- [ ] **附录**（如有）：调查问卷、数据表格、长列表等

### 3.2 学术质量检查

- [ ] **创新性**：核心创新点是否表述清晰？（至少 1 个，博士学位论文建议 2-3 个）
- [ ] **论证深度**：主要论点是否有充分的论证过程？
- [ ] **文献综述**：是否系统全面？是否指出了研究缺口？
- [ ] **研究方法**：方法选择是否合理？是否有方法论的自觉？
- [ ] **数据/案例**：案例引用是否准确？数据来源是否可靠？
- [ ] **逻辑结构**：各章之间是否有清晰的逻辑关系？

### 3.3 格式规范

- [ ] **字体字号**：是否符合学校学位论文格式要求？（各校不同）
- [ ] **行间距**：是否符合要求？
- [ ] **页眉页脚**：是否按学校模板设置？
- [ ] **页码**：封面、目录、正文页码格式是否正确？
- [ ] **参考文献格式**：是否统一使用 GB/T 7714 或学校规定的格式？
- [ ] **图表编号**：是否有连续编号？是否有图名/表名？
- [ ] **脚注格式**：是否统一？

### 3.4 答辩准备

- [ ] **答辩陈述稿**：15-20 分钟，覆盖研究问题、方法、核心论证、创新点
- [ ] **PPT**：简洁清晰，重点突出论证逻辑
- [ ] **预设问题**：预判答辩委员会可能提出的问题，准备回答
- [ ] **论文打印**：按照答辩委员会人数准备打印稿
- [ ] **最终校对**：答辩前至少通读全文 1 遍修正错误

## 四、通用润色清单

### 4.1 语言表达

- [ ] **错别字**：全文逐字检查（建议使用"朗读"功能辅助）
- [ ] **病句**：主谓宾是否完整？修饰语和中心语是否搭配？
- [ ] **口语化**：是否有"搞清楚""没法""挺多的"等口语表达？
- [ ] **过度抽象**：是否有连续多段没有具体案例或法条支撑？
- [ ] **句子过长**：是否有超过 80 字的长句需要拆分？

### 4.2 逻辑连贯

- [ ] **论点可一句话概括**：每章每节的论点是否清晰？
- [ ] **段落过渡**：段落之间是否有逻辑衔接？
- [ ] **论证递进**：论证是否有层次感（事实→归因→理论→方案）？
- [ ] **结论回扣**：结论是否回扣了具体论点（而非空泛总结全文）？

### 4.3 引用规范

- [ ] **法条准确**：所有法条引用是否准确（条、款、项）？
- [ ] **案例准确**：所有案例的法院名称、案号、裁判要旨是否准确？
- [ ] **文献准确**：作者姓名、论文标题、期刊名、年份、页码是否核对？
- [ ] **格式统一**：所有引用格式是否统一？
- [ ] **无编造**：是否有未核实来源的引用？（这是学术不端）

### 4.4 排版格式

- [ ] **标题编号一致**：全文标题编号格式是否统一？
- [ ] **字体字号一致**：标题、正文、注释的字体字号是否全文一致？
- [ ] **标点符号**：是否使用全角标点（中文论文）？
- [ ] **引号规范**：引用原文用双引号""，强调用单引号''（或书名号《》）
- [ ] **注释编号**：脚注编号是否连续、格式是否统一？

### 4.5 去 AI 味快速检查

- [ ] **AI 词汇密度**：每段中"综上所述""值得注意的是""应当指出"等词是否超过 1 个？
- [ ] **模糊归因**：所有"学界认为""通说认为"是否有具体出处？
- [ ] **案例重要性**：是否将普通案例夸大为"里程碑式"？
- [ ] **段落长度**：段落长度是否有变化（是否每段都差不多长）？
- [ ] **小标题**：小标题是否反映具体论点（而非模板化表达）？
