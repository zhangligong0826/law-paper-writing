# 引用规范详解

> 法学论文引用是学术诚信的基石。本文档系统梳理中文法学论文常用的引用规范，涵盖法律条文、司法案例、学术文献三大类引用场景。

---

## 一、法律条文引用

### 1.1 现行法律

**基本格式：**

```
《中华人民共和国XX法》第X条第X款
```

**示例：**
- 《中华人民共和国民法典》第577条
- 《中华人民共和国民法典》第580条第1款第1项
- 《中华人民共和国公司法》第15条

**注意事项：**
- 全称引用，不使用简称（首次出现时）
- "条"用汉字，不用阿拉伯数字
- 款、项用阿拉伯数字
- 如需引用连续条文：第X条至第Y条
- 如需引用全文或部分条文，在注释中完整引述

### 1.2 法律修正/修订

**修订后的法律引用当前生效版本：**

```
《中华人民共和国XX法》（20XX年修正）第X条
```

**示例：**
- 《中华人民共和国刑法》（2023修正）第133条之一
- 《中华人民共和国著作权法》（2020修正）第10条

**注意事项：**
- 引用旧版本条文时需标注："(20XX年修正前)第X条"
- 标明修正/修订年份，便于读者确认

### 1.3 司法解释

**基本格式：**

```
《最高人民法院关于适用〈中华人民共和国XX法〉若干问题的解释（X）》第X条
```

**示例：**
- 《最高人民法院关于适用〈中华人民共和国民法典〉总则编若干问题的解释》第1条
- 《最高人民法院关于审理民间借贷案件适用法律若干问题的规定》（2020年修正）第25条

### 1.4 行政法规、部门规章

**行政法规：**
- 《XX条例》
- 《XX规定》

**部门规章：**
- 《XX办法》
- 《XX实施细则》

**注意：** 需标明发布机关和发布年份

### 1.5 国际条约

**中国已加入的条约：**
- 《联合国国际货物销售合同公约》第XX条
- 《保护工业产权巴黎公约》第X条

**未生效或未加入的条约引用时需说明：**
- 我国尚未加入的条约：在引注中注明"我国尚未加入"

## 二、司法案例引用

### 2.1 最高人民法院指导性案例

**格式：**

```
最高人民法院第XX号指导性案例
```

**示例：**
- 最高人民法院第1号指导性案例（上海中原物业顾问有限公司诉陶德华居间合同纠纷案）

**注意：** 最高人民法院指导性案例具有"应当参照"的效力，引用时应当标注案例编号和裁判要旨

### 2.2 最高人民法院公报案例

**格式：**

```
《最高人民法院公报》XXXX年第X期
```

**示例：**
- 《最高人民法院公报》2023年第5期（案例名称）
- 或：(2023)最高法民终XX号

### 2.3 一般裁判文书

**格式（推荐）：**

```
审级法院 + 案号 + 当事人
```

**示例：**
- 最高人民法院(2023)最高法民申XX号裁定书
- 北京市第一中级人民法院(2023)京01民终XX号判决书

**注意事项：**
- 一审、二审、再审应区分标注
- 引用裁判要旨时，应准确引述，可加引号
- 标注审理法院、案号，便于读者检索

### 2.4 地方法院案例

**注意事项：**
- 地方法院案例（非最高法）不具有判例效力，引用时作为论证辅助材料
- 引用时应说明该案例在本论文论证中的作用（类比论证/补充论证/反面论证）
- 涉及地方司法差异的讨论（如"同案不同判"）时，地方法院案例才有较高引用价值

### 2.5 涉外案例引用（英文）

**Bluebook 基本格式：**

```
Party v. Party, Volume Reporter Page (Court Year)
```

**示例：**
- Marbury v. Madison, 5 U.S. (1 Cranch) 137 (1803)
- Donoghue v. Stevenson, [1932] A.C. 562 (H.L.)

**注意：** SSCI 投稿时按目标期刊的引用规范引用涉外案例

## 三、学术文献引用

### 3.1 GB/T 7714-2015 规范

这是中文法学论文最常用的引用规范。

#### 期刊论文

**格式：**

```
[序号] 作者. 论文标题[J]. 期刊名称, 年份, 卷(期): 起止页码.
```

**示例：**
```
[1] 王利明. 论民法典的时代特征与编纂步骤[J]. 中国法学, 2014(5): 32-45.
[2] 梁慧星. 民法典编纂的若干理论问题[J]. 中外法学, 2016(4): 976-994.
[3] 崔建远. 合同法总论(中卷)[M]. 北京: 中国人民大学出版社, 2016: 289.
```

#### 专著

**格式：**

```
[序号] 作者. 书名[M]. 出版地: 出版社, 年份: 引用页码.
```

**示例：**
```
[1] 王泽鉴. 民法学说与判例研究(第一册)[M]. 北京: 北京大学出版社, 2009: 56.
[2] 拉伦茨. 法学方法论[M]. 陈爱娥, 译. 北京: 商务印书馆, 2003: 112.
```

#### 编著

**格式：**

```
[序号] 作者. 章节标题[A]. 编者. 书名[C]. 出版地: 出版社, 年份: 引用页码.
```

**示例：**
```
[1] 张新宝. 侵权责任构成要件[A]. 王利明. 民法典侵权责任编研究[C]. 北京: 中国人民大学出版社, 2016: 89.
```

#### 硕博学位论文

**格式：**

```
[序号] 作者. 论文标题[D]. 城市: 学校名称, 年份.
```

**示例：**
```
[1] 李永军. 论民法典中的物权变动模式[D]. 北京: 中国政法大学, 2018.
```

#### 网络文献

**格式：**

```
[序号] 作者. 标题[EB/OL]. 网站名称, 发布日期(或更新日期)[引用日期]. URL.
```

**示例：**
```
[1] 最高人民法院. 最高人民法院关于适用《中华人民共和国民法典》总则编若干问题的解释[EB/OL]. (2022-02-25)[2024-03-15]. https://www.court.gov.cn/...
```

#### 报纸文章

**格式：**

```
[序号] 作者. 标题[N]. 报纸名称, 年-月-日(版次).
```

**示例：**
```
[1] 周强. 深入学习贯彻习近平法治思想 不断推进人民法院工作高质量发展[N]. 人民法院报, 2023-03-10(1).
```

### 3.2 多作者引用规则

| 作者数量 | 引用规则 |
|---------|---------|
| 1-3 人 | 列出全部作者 |
| 4 人及以上 | 列出前3人+等（中文）/ et al.（英文） |
| 2 人合著 | 作者之间用顿号 |
| 译者 | 在书名后标注译者 |

**示例：**
```
[1] 王利明, 崔建远, 杨立新. 合同法研究(修订版)[M]. 北京: 中国人民大学出版社, 2015: 123.
[2] 张明楷, 陈兴良, 周光权, 等. 刑法学者论集[C]. 北京: 北京大学出版社, 2018: 45.
```

### 3.3 CSSCI 引注特殊要求

**部分 CSSCI 期刊有自己的引注规范，与 GB/T 7714 有差异：**

| 期刊 | 特殊要求 |
|------|---------|
| 法学研究 | 脚注式引注，不使用文中[序号]方式 |
| 中国法学 | 脚注式引注，首次引用需完整信息 |
| 法学 | 脚注式引注，同一文献再次引用可简略 |
| 中外法学 | 脚注式引注，外文文献有特殊格式 |
| 政法论坛 | 脚注式引注 |
| 法律科学 | 脚注式引注 |

**建议：** 投稿前务必查看目标期刊的"投稿须知"或"作者指南"，确认引注规范

## 四、英文文献引用（SSCI 投稿）

### 4.1 Bluebook 21st Edition 基础

**期刊论文：**

```
Author, Title, Volume Journal Page (Year)
```

**示例：**
```
Richard A. Posner, An Economic Theory of Criminal Law, 85 Colum. L. Rev. 1193 (1985).
```

**专著：**

```
Author, Title (Edition Year)
```

**示例：**
```
H.L.A. Hart, The Concept of Law (3rd ed. 2012).
```

**编著章节：**

```
Author, Title, in Editor, Book Title (Edition Year)
```

**示例：**
```
Guido Calabresi, The Problem of Malpractice, in Essays in Law and Economics 1 (Michael J. Trebilcock ed., 1986).
```

### 4.2 Bluebook 缩写速查

| 期刊全称 | Bluebook 缩写 |
|---------|---------------|
| Harvard Law Review | Harv. L. Rev. |
| Yale Law Journal | Yale L.J. |
| Columbia Law Review | Colum. L. Rev. |
| University of Chicago Law Review | U. Chi. L. Rev. |
| Stanford Law Review | Stan. L. Rev. |
| Michigan Law Review | Mich. L. Rev. |
| Law & Society Review | Law & Soc'y Rev. |
| American Journal of International Law | Am. J. Int'l L. |
| Journal of Legal Studies | J. Legal Stud. |

### 4.3 ALWD Citation Manual

ALWD（Association of Legal Writing Directors）格式与 Bluebook 类似但有细微差异：
- 更注重实务性，是部分美法学院写作课的标准教材
- Bluebook 更侧重学术出版
- SSCI 投稿时以目标期刊要求为准

### 4.4 SSCI 法学期刊投稿引用注意

- 严格按照目标期刊的作者指南排版引用
- 中英文文献混合引用时，注意格式统一
- 法条引用需同时提供中英文（如有英译本）
- 部分期刊要求附录参考文献列表（而非纯脚注）

## 五、文献管理工具

### 5.1 主流工具对比

| 工具 | 优势 | 劣势 | 适用场景 |
|------|------|------|---------|
| **Zotero** | 免费开源，中文文献支持好，插件丰富 | 需要手动维护引注格式 | 推荐：中文法学研究首选 |
| **EndNote** | 功能强大，Word集成好 | 收费，中文支持一般 | 英文SSCI投稿 |
| **Mendeley** | 免费，社交功能，PDF标注好 | 引注格式自定义能力弱 | 辅助阅读管理 |

### 5.2 中文法学文献管理注意事项

- 中国知网文献可直接导出到 Zotero（使用浏览器插件）
- 北大法宝文献需要手动建立引文条目
- 著作类文献需手动录入，注意核对出版社和页码
- 法条和案例不通过文献管理工具管理，在文档中直接引用

### 5.3 引用自动格式化的局限性

- 自动格式化无法处理脚注式引注（多数CSSCI期刊使用脚注）
- 法律条文的引用格式不适用于文献管理工具的标准模板
- 建议手动管理法律条文和案例引用，仅用文献管理工具管理学术文献
- **最终提交前必须人工逐条核对引用格式**
